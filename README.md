# Plan a dependency review from public release cadence

A long interval between releases can affect upgrade planning. It does not establish that maintainers have stopped working. This study will test a small retrospective release-gap benchmark and a local review exercise, using a fixed cohort of eight public repositories.

**State: protocol only.** No data cohort, predictive result, deployment or actual maintenance interruption is established. The [protocol](PROTOCOL.md) fixes source bounds, time and repository separation, candidate settings and publication checks. A current API snapshot cannot recreate the original historical availability of edited or deleted release records.
