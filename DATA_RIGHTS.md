# Source and public-package boundary

This package uses minimal factual metadata from GitHub's public release API: repository/release IDs, timestamps, source-state flags and hashes. GitHub documents public reads of published releases and explains that ordinary Git tags are a separate endpoint. API use follows the [GitHub terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service), documented rate limits and pagination. No repository assets, source archives or code are downloaded.

Complete API responses remain private. Their release prose, author profiles, avatars, asset URLs and other excluded fields are not redistributed. This project's license covers its new code and writing; it does not license third-party GitHub content or imply endorsement by the named projects. Current public metadata may include edits and omit deleted releases. Its historical publication timestamps do not prove that the same records were available at an earlier prediction origin.

The original GH Archive proposal is retained in the program catalog. Its [publisher clarification](https://github.com/igrigorik/gharchive.org#licenses) distinguishes MIT code/documentation and website licensing from third-party rights in event archives. No GH Archive event data, contributor profile or developer employment judgment is included in this exact study.

Independent program manuscripts may be published after source, numerical, privacy and rendered-document checks. Formal-publication projects, including the separate Azure optimization study, remain excluded.
